# Vitamova

### About

This is a [Django](https://github.com/django/django) Web Application for intermediate to advanced language learners. The application can be accessed [here](https://app.vitamova.com/).

## Compatability

This application has been tested and run in Ubuntu 24.04 LTS.

## Sections

The application has 3 parts: webapp, vitalib, and deploy.

### webapp

webapp is the Django application which actually serves the webpages.

### vitalib

Vitalib is a [Python](https://www.python.org/) library with functions used regularly in the app.

### deploy

Deploy includes all scripts needed to deploy this application on Ubuntu.
